# 超频 OVERCLOCK · 离线题库学习终端

> 原生 JavaScript 单页应用 + Electron 桌面封装。一个人从内容数据工程做到打包分发。
>
> ⚠️ **本仓库是「代码展示版」**：已剔除题库数据、图片素材与第三方平台对接模块，原因见文末《本仓库未包含的内容》。仓库只承载我自己写的代码。

---

## 它是什么

面向公务员考试行测科目的**自持式离线学习终端**。设计目标是把「背知识」和「练题目」合到一个界面里，全部内容离线可用、学习进度只存在本机，不联网、不登录、不依赖任何平台账号。

内容规模（生产环境）：

| 内容 | 数量 |
|---|---|
| 知识卡 | 1853 张（9 个模块，按考试逻辑排序） |
| 历年真题 | 14827 道（2017–2026 国考 / 省考 / 联考） |
| 易混辨析 | 3224 组 / 4638 词 |
| 带原卷图的题 | 1095 道（其中图形推理 862 道） |
| 时政月报 | 241 期 |
| 图推思维导图 | 379 节点 / 148 张图 |

交付形态：Electron 安装版 / 便携版 / 自解压版，以及用系统浏览器实现的零安装绿色版。

## 技术亮点

| 能力 | 实现方式 |
|---|---|
| **零框架单页应用** | 纯原生 HTML / CSS / JavaScript，无任何前端框架与构建步骤。`app.js` 约 250 KB，`app.css` 约 47 KB |
| **万级题库的前端性能** | 14827 道题按「模块 + 题型」切分成 62 个独立数据分片，**进入练习时才按需加载对应分片**，避免首屏载入全量题库 |
| **手写 Canvas 画板** | `scratch.js`：直接在题目/材料图上圈画重点数据，支持黑笔 / 红笔 / 橡皮 / 撤销 / 清空 / 透明度调节，**笔迹跟随题目存档**，下次打开还在 |
| **本地持久化与迁移** | `localStorage` 存储学习进度，写盘做 **120 ms 防抖**；提供 JSON 导出 / 导入，用于换机迁移与备份 |
| **复习调度算法** | 艾宾浩斯间隔 1 / 2 / 4 / 7 / 15 / 30 天：「已记住」递进到下一档，「忘了」次日重现，首页显示今日到期数量 |
| **主题系统** | CSS 变量驱动的多皮肤切换（`skin.js`），不刷新页面热切换 |
| **桌面封装与分发** | Electron 33 + electron-builder，`asar: false` 便于增量更新；产出 NSIS 安装版 / 便携版 zip / 自解压版，配置中英文语言包与自定义图标 |
| **零安装「伪原生」体验** | PowerShell 启动器自动探测 Edge / Chrome，以 `--app=` 应用窗口模式打开（无地址栏、无标签栏，形似原生软件）；支持全屏 / kiosk / 独立数据目录 |
| **本地 AI 助教** | Python 嵌入服务（`embed_server.py`）+ 结构化提示词模板（`xingce-skill.md`、`shenlun-skill.md`），把题目上下文拼成提问文本 |

## 架构

三层，每层职责单一：

```
内容层   PDF / Markdown / XMind  ──►  结构化数据
        题库按「模块＋题型」切分为 app/data/bank/bank_*.js，按需载入
        知识卡 / 易混辨析 / 时政 / 导图各自一个数据模块
                    │
应用层   零框架原生单页应用
        app.js（业务）· app.css（布局）· scratch.js（Canvas 画板）
        localStorage['xcterm_v1'] 存进度 · CSS 变量做主题
                    │
外壳层   ① 绿色便携：PowerShell 探测浏览器 → --app 应用窗口模式，零安装
        ② 桌面安装：Electron 33 + electron-builder → NSIS / 便携 / 自解压
```

## 关键难点与解法

这部分是项目里真正费时间的四个问题。

### 1. 14827 道题不能全量加载

全量题库是 31 MB 的数据分片，一次性载入会让首屏卡死。解法是**按「模块＋题型」二维切分**成 62 个独立分片（`app/data/bank/bank_*.js`），配合一份索引（`bankindex.js`），进入某类练习时才动态载入对应分片。

### 2. 1095 道带原卷图的题目

图形推理、资料分析、数量关系的题干里有示意图、几何图、图表材料，纯文本抽取会丢掉全部图形信息。解法是**从原卷 PDF 里把题干图与四个选项图整块抠出**并离线打包，答题界面直接「看图选字母」，完全离线可用。

### 3. 路径含中文或空格时 `--app` 被静默忽略

绿色版依赖 `浏览器 --app=<file:// URL>` 来做出无地址栏的原生窗口观感。但 Windows 下路径含中文或空格时，浏览器会**静默忽略** `--app` 参数，直接退化成普通标签页——不报错，只是行为不对。解法是构造 `file://` URL 时做**百分号编码**，并处理盘符与 UNC 前缀。

### 4. 解析「不像老师讲课」

全库审计（14827 题逐题检查）发现：解析正文 100% 是第三方机构原始解析，只有约 2% 带解题体系语言。也就是做错的题只能告诉你「答案是什么」，不告诉你「这类题该怎么做」。

解法是把「老师思路」抽象成挂在每道题上的**题型卡**（208 种，含识别信号 / 标准动作 / 常见坑），再用「教练带路」模板改写解析：题型定位 → 思路带路 → 选项过堂 → 答案 → 坑与复盘。按模块分批改造，不改动原始解析。

## 运行

外壳层可以直接跑：

```powershell
npm install          # 安装 electron / electron-builder
npm start            # 以 Electron 启动
.\启动.cmd            # 或以「系统浏览器 + 应用窗口模式」启动，无需 npm
```

⚠️ **但本仓库不包含 `app/data/` 与 `app/assets/`**，因此启动后是一个空壳界面，无法做题。这是刻意的，见下节。要完整运行需自行准备内容数据。

`.npmrc` 里配置了 npmmirror 镜像，因为 Electron 与 electron-builder 的二进制在国内直连 GitHub Releases 基本拉不动。

## 本仓库未包含的内容

公开仓库只放代码，以下内容**刻意不包含**，同时说明原因：

| 未包含 | 原因 |
|---|---|
| `app/data/**`（真题、解析、辨析、时政） | 历年真题与机构解析涉及第三方著作权，不在公开仓库分发 |
| `app/assets/**`（原卷图、素材、音频） | 同上；且体积达 195 MB |
| `app/deep/shenlun/**` | 第三方课程讲义原文 |
| `fenbi-*.js`、`server.mjs`、`ncm.mjs`、`fenbi-sync/` | 与第三方平台对接的本地数据回流模块，涉及平台服务条款，不公开 |
| 登录凭证、Cookie、账号配置文件 | 个人信息 |

所以这个仓库的定位是**代码展示**：工程结构、算法实现、桌面封装与分发方案都是完整可读的，业务数据需要自行准备。
