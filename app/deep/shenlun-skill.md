# 申论讲题 playbook

## 〇、总纲：申论为什么能拿分

申论除大作文外**都是采点给分**——阅卷人按一张「参考答案要点表」给分，写到就给，写不到就不给；再给结构条理和卷面几分。所以整条流水线的目标只有一个：**把材料里的得分点，用规范的话、完整的条数、在字数内写出来。**

四句话概括：
1. 题干定方向（题型 + 对象 + 范围 + 分值 + 字数）。
2. 材料定内容（**要点必须有出处，材料原词优先**）。
3. 分值定条数（20 分 ≈ 5 个点左右，10 分 ≈ 3-4 个点，每题总字数 ÷ 每条 30-50 字）。
4. 表述定档次（总括句 + 分条 + 动宾短语 + 政府语体）。

**反面清单（学员最常见的失分方式，批改时优先查这几项）**：漏段落（只读前两段）／漏主体（只写政府做法，漏企业群众）／同义要点不合并（五条其实是一个点）／没有总括句（阅卷人找不到你答的是什么）／超字数／把脑子里的一般政策常识当要点（材料里没有）／抄题干当答案。

## 一、审题：把题干拆成六个格子

| 格子 | 看什么 | 影响 |
| --- | --- | --- |
| 题型 | 概括 / 分析 / 提出对策 / 公文 / 大作文 | 决定整篇结构 |
| 作答对象 | 概括「做法」还是「问题」还是「原因」 | 对象错=0 分 |
| 材料范围 | 「根据给定资料 3」还是「结合给定资料」 | 越界用别处=失分 |
| 分值 | 10 / 15 / 20 / 25 分 | 定要点条数 |
| 字数 | 「不超过 300 字」「100-150 字」 | 硬约束，超了扣分 |
| 特殊要求 | 有条理 / 观点明确 / 具体可行 / 联系实际 | 定加工方式 |

**动词对照**：概括（归纳、总结、概述）= 忠于材料，做减法；分析（谈谈你的理解、说明理由、分析变化、谈启示）= 材料 + 判断，可加一层结论；提出对策（就……提出建议）= 材料对策优先，问题反推补充；公文（起笔一份……）= 文种 + 内容双合规；大作文 = 立意先行。

## 二、各题型作答框架

### 1. 概括题（最常考，也最不该丢分）

**框架**：总括句 + 分条要点（要点 = 动宾短语 + 具体表现/手段）

- 概括**对策/做法**：谁 + 做了什么 + 达到什么效果（"做了什么"是得分点核心）。材料里的做法常常散在案例里——把案例里的人话翻译成工作语言（"马阿姨把娃放到宝宝屋" → "建设嵌入式社区托育点"）。
- 概括**问题**：现状 + 消极表述。用"……不足/缺失/滞后/不畅/不到位"。别把原因写成问题（"资金缺乏"是原因，"投入不足"是问题）。
- 概括**原因**：多问"为什么"。分主客观 / 内外因 / 直接间接。警惕：材料里原因往往是一句带过，要抓住因果词（因为、由于、之所以、导致、使得）。
- 概括**作用/意义**：积极影响，"有利于/促进了/提升了/推动了"。常说对象（对谁的作用）和领域（经济/社会/文化/生态/民生）。
- 概括**综合**（一道题里两问）：按问作答，分两段写，问什么答什么顺序，别混在一起。

**要点筛选四问**：是材料原话的意思吗？跟对象直接相关吗？和已写的某条重复吗？能不能用 15 个字说清？

### 2. 分析题

- **词句理解**（"谈谈你对'xxx'的理解"）：① 解释该词句在材料中的含义（表层 + 本质）② 结合材料展开（表现 / 原因 / 影响 / 涉及的主体）③ 给结论或对策。"这句话"往往暗含一个判断，答题要把它点破。
- **启示分析**（"某某做法给我们什么启示"）：把具体做法**抽象成普适道理**（"某市建了 300 个驿站" → "要完善基层服务设施，方便群众就近办事"）。一定写成"要……"的普适表述，不要复述案例。
- **变化分析**（"发生了哪些变化"）：**前 vs 后对比**是唯一正确的写法——"从……到……"。只写现状不得分。常见维度：观念、方式、效率、主体、结果。
- **观点/关系分析**（"有人认为……你怎么看"）：一分为二 → 合理之处 + 不足之处 + 你的判断 + 建议，不能只站一边。

### 3. 提出对策（含复合对策）

**三个来源，按优先级**：
1. **材料里直接给了对策**（某人说"应该……"、某文件规定）——直接用，别自己另编。
2. **由问题反推**：把问题句翻转成对策句（"监管缺失" → "明确监管责任，建立日常巡查和举报机制"）。
3. **由案例经验反推**：别人的成功做法抽象化。

**配点方法**（想不出办法时的拐杖，选顺手的用）：
- 主体法：政府（制度/监管/投入/服务）、企业（技术/产品/责任）、社会组织（桥梁/公益）、个人（意识/参与）、媒体（宣传/监督）、学校（教育）。
- 维度法：制度、资金、人才、技术、监管、宣传、服务、协作。
- 流程法：事前（立法/标准/规划）、事中（执行/协调/监督）、事后（考核/问责/总结推广）。

要求里写"具体可行"就必须有**主体 + 动作 + 手段**，不要写"要重视""要加强"。

### 4. 公文写作（文种决定格式与语气）

**万能步骤**：判文种 → 定格式（标题 / 称谓 / 正文 / 落款日期）→ 定内容（依据材料：做了什么、要做什么）→ 控语言（对上汇报稳重、对外宣传亲切、发布词有仪式感）。

| 文种 | 格式要点 | 内容要点 |
| --- | --- | --- |
| 措施内容 | 标题 + 正文分条 | 就是一份"对策清单"，写成"一要……二要……"或分段措施 |
| 案例摘要 | 标题 + 正文 | 推荐理由 + 案例经过（谁、做了什么、取得什么成效）+ 评价 |
| 推荐材料 | 标题 + 称谓 + 正文 + 落款 | 推荐对象 + 事迹 + 推荐意见 |
| 汇报提纲 | 标题 + 正文分块 | 情况（成效）+ 问题 + 下一步打算，纵向展开 |
| 简报 | 标题 + 导语 + 主体 + 结尾 | 导语概述（何时何地何事），主体分点，结尾总结/展望 |
| 发布词 | 标题 + 称谓 + 正文 + 落款 | 背景意义 + 主要内容/亮点 + 表态与展望，语气庄重 |
| 宣传稿 | 标题 + 正文 | 造势引题 + 做法亮点 + 号召呼吁，可活泼 |

**公文铁律**：标题=发文单位+事由+文种（题干没给单位就不硬编）；内容 100% 来自材料；不要写"以上是我单位关于……的报告"这种套话占字数。

### 5. 大作文（40 分）

**① 立意（决定档次）**：找题干关键词 + 材料反复出现的核心句 → 形成一个**判断句**（"要……""……是……的关键"）。判断是"话题"还是"观点"：给一句话（如"慢下来才能走得远"）就是观点，必须围绕它写，不能换成自己的话题。

**② 结构（五段式最稳）**：
```
开头：引题（现象/名言/政策）→ 分析（为什么重要/有什么问题）→ 亮总论点    ≤150 字
分论点段 A：分论点句 + 阐释 + 论据（材料例 + 自身积累）+ 回扣
分论点段 B：同上（与 A 不交叉）
分论点段 C（可选）：递进或并列最后一层
结尾：总结分论点 + 升华（站到发展/民生/治理的高度）    ≤120 字
```

**③ 分论点设计**：
- 并列式：意义型（有利于……）／原因型（因为……）／对策型（要……）。
- 递进式：是什么 → 为什么 → 怎么办。
- 每个分论点必须**能被一句话说清**，且相互独立；分论点句放段首，用判断句，不用疑问句。

**④ 标题**：主标题点观点 + 可加副标题。公式：动词+核心词（"以创新驱动高质量发展"）／对照式（"大处着眼，小处着手"）／比喻式（"筑牢……的堤坝"）。忌无观点、无对象、超 14 字。

**⑤ 语言**：政论语体，短句、排比、对仗；段内不出废话；不写成公文（不要"现将有关情况汇报如下"），不写成抒情散文。

## 三、批改学员答案的固定流程（这是本技能最常用的用法）

1. **先核对硬约束**：字数、条数、对象、范围。超字数 / 答错对象先点出来（这是最容易改的丢分）。
2. **列要点表**：从材料里列出应当命中的要点（一般按分值 5 个点 / 20 分），标注出处段落。
3. **逐条比对**：命中（√）／意思对但表述不合规（△）／漏（×）／材料没有的废话（-）。
4. **折算失分**：要点分 + 条理分 + 卷面分，给区间（"这题大概 12-14 分/20"），不要给精确到小数的假精确。
5. **给改写稿**：按规范格式重写一遍参考答答案，守字数。
6. **给一条下次就能用的动作**（例如"下次先给材料每段标 1-4 类，标完再动笔"）。

**输出用这个格式**：
```
【审题】题型 · 对象 · 范围 · 分值 → 要点数 · 字数
【要点定位】第 X 段 → 要点 n（类别）
【参考答案】（守字数）
【你的答案】命中 n 个 / 漏 n 个：……
【失分点】……
【提升动作】……
```

| 概括对策 | `概括对策`（小讲义 6 份 + 方法实战班「概括题【概括对策1-3】」）+ `赠送刷题` |

| 公文写作 | `方法实战班` → `公文写作【措施内容/案例摘要/推荐材料/汇报提纲/简报/发布词/宣传稿】` |

**用法**：学员问到具体题型，先用检索把该题型的方法段和范文段捞出来，**按袁东体系的口径讲**（学员正在跟他这套课），不要另创一套方法名词。找不到相关材料就直说，再用通用方法补。
